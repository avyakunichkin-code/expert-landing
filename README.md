# Живые продажи в эпоху цифровизации

Самостоятельный статический лендинг мастер-класса Алёны Мельник.

Для локального просмотра запустите `node preview.mjs` и откройте http://127.0.0.1:4194/.
Для публикации достаточно файлов index.html, styles.css, interaction.js и portrait.png.
design-qa.md содержит заметки о прежней версии страницы.
